# www.telx.network

This repository controls the [www.telx.network](https://www.telx.network) website.

The TELx site is a Single Page Application (SPA) built in React.js (Next.js). Styles are written in Tailwind. Content is delivered from Contenful.
More information can be found here: [https://docs.google.com/document/d/1SIIJRj3wH924lAklmWull_Z2kS8tuwQzhv8Nt4Olw_Q/edit#heading=h.r9vmg1a2ooq4](https://docs.google.com/document/d/1SIIJRj3wH924lAklmWull_Z2kS8tuwQzhv8Nt4Olw_Q/edit#heading=h.r9vmg1a2ooq4)

Production: [https://telx.network](https://telx.network)

If you need access to content updating, contact Josh at josh@telco.in.

## Installation

Install the latest `node_modules`
`npm ci`
Make sure you have a copy of the requisite environment variables. Copy `.env.sample` and rename it to `.env.local`. Reach out to @leopashov for the latest copy of credentials.

### Run Dev Server

`npm run dev`
