The Telcoin Platform is a user-owned, decentralized platform powered by the Telcoin Association, application users and developers, and GSMA member Mobile Network Operators (MNOs). 

# Platform Architecture
![V3_Platform_Stack.jpg](/aboutMedia/V3_Platform_Stack.jpg)


### Telcoin Application Network
**Description:** Any GSMA member can develop and deploy decentralized applications (dApps) that are integrated with the Telcoin Platform and run on the Telcoin Network. Together, they form the Telcoin Application Network. They can earn TEL issuance benefits from the Association as well as participate in Association governance.

### TELx Exchange Layer
**Description:** TELx is a liquidity network powered by active Telcoin users across decentralized financial protocols. TELx is designed to power a global suite of fast, affordable, decentralized, and user-owned financial products for every mobile phone subscriber in the world.

### TEL Token
**Description:** The Telcoin (TEL) Token is the native token of the Telcoin Platform, and the gas fee token of the Telcoin Network. It connects all layers of the Telcoin Platform.

### Telcoin Network
**Description:** [Telcoin Network](https://www.telcoin.network/) is an EVM-compatible, public blockchain secured globally by GSMA Operator Member MNOs using Proof-of-Stake consensus. The system serves as the underlying blockchain architecture securing private property rights over digital assets and enabling on-chain protocols and applications in the Telcoin Platform.

### Telcoin Association
**Description:** The Telcoin Association governance system comprises of a set of governance organizations and rules that shape the behavior of [Association Miners](https://www.telcoin.org/documentation/miners) (Stakers, Developers, Liquidity Miners, and Validators) within the Telcoin Platform.
